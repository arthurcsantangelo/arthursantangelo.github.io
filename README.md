# arthursantangelo.github.io

## Exemplo de testes com Jest

O projeto inclui um exemplo de operações matemáticas em `src/matematica.js`
com testes automatizados em `tests/matematica.test.js`.

Para executar os testes, instale as dependências e rode o comando:

```bash
npm install
npm test
```

Os testes verificam soma, subtração, multiplicação, divisão e o erro esperado
ao tentar dividir por zero.
